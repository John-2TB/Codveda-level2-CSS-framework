# Pepsi Landing Page

A modern Pepsi-inspired landing page built with **Tailwind CSS** and **GSAP**. The project focuses on responsive UI design, utility-first CSS, and smooth web animations.

## 🚀 Features

- Modern Pepsi-inspired landing page
- Responsive layout
- Hero section with promotional content
- Product showcase section
- About Us section
- Navigation menu
- Product carousel/navigation controls
- Call-to-action buttons
- Smooth animations powered by GSAP
- Utility-first styling with Tailwind CSS

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- GSAP
- Vite

## 🎨 Design

The website uses a dark visual theme combined with Pepsi's recognizable blue, red, and white branding.

The page includes:

- Hero banner
- Promotional content
- Product showcase
- About section
- Footer
- Interactive elements and animations

## ✨ Animations

GSAP was used to create smooth animations and enhance the overall user experience.

The animations help bring elements of the landing page to life while maintaining a clean and modern interface.

## 💻 How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```
2. Open the project folder in VS Code.
3. Install the dependencies:
```bash
npm install
```
4. Start the development server:
```bash
npm run dev
```
5. Open the local development URL provided by Vite in your browser.

This project was created as part of the Codveda Internship – Level 2 to demonstrate practical skills in CSS frameworks, responsive web development, JavaScript, UI implementation, and web animations.
